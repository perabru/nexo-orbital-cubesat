# Como usar o quadro

1. Abra `index.html` ou o endereço publicado no GitHub Pages.
2. Organize colunas por frente ou por estado. No computador, arraste cartões para mover e reordenar.
3. No celular ou pelo teclado, abra uma tarefa e use os campos de frente e estado.
4. Edite datas, responsável, prioridade, checklist, pré-requisitos, notas e link da evidência. Use **Salvar alterações**.
5. Para concluir, todos os critérios e pré-requisitos devem estar concluídos.
6. Use busca, filtros, linha do tempo e calendário para acompanhar prazos.
7. Arquivar é reversível: filtre **Arquivadas**, abra o cartão e restaure.
8. Em **Backup e exportação**, exporte JSON, CSV ou ICS; a impressão reúne todo o plano.

## Persistência e compartilhamento

As alterações são salvas apenas no navegador e projeto atuais. Não há autenticação ou edição simultânea automática. Para compartilhar andamento, exporte JSON e importe no mesmo projeto no outro navegador. A importação substitui os dados locais e aceita desfazer nesta sessão. O arquivo `plano-inicial.json` contém o plano original.

Desfazer mantém até 20 mudanças durante a sessão. O navegador não substitui um backup. O código e o plano padrão estão no GitHub; os dados editados no navegador não são enviados ao repositório.
