# Kit de estudos - NEXO ORBITAL

Exercícios autorais, dados demonstrativos sintéticos e formulários de trabalho. Não há livros ou cursos de terceiros redistribuídos neste pacote. As referências ficam ligadas às fontes originais na trilha e na matriz de referências.

## Comece aqui
1. Leia a trilha em docs/trilha-de-estudos.md no repositório ou na aba Trilha de estudos do site.
2. Estude os módulos na ordem indicada, começando em fevereiro de 2027.
3. Python 3 e/ou uma versão suportada de Node.js são suficientes para os exercícios locais. Os scripts Python usam somente a biblioteca padrão. O gerador HLS também requer FFmpeg.
4. Extraia o ZIP antes de executar. Rode os comandos no diretório que contém este arquivo:

```text
python validar_telemetria.py
```

Os testes de domínio são didáticos: votação não classifica risco oficial de extinção, a previsão de frames não é um produto do INPE, o preço calculado não cobra um cliente e sinais sintéticos não comprovam desempenho de instrumento.

## Trabalho acadêmico
Use diario_de_bordo.csv, matriz_referencias.csv, bom.csv e protocolo_experimento.md para documentar decisões e ensaios reais. Anote datas, versões, perdas e limitações. Não apresentar números deste conjunto sintético como resultado de campo.

## Hardware
A BOM é um inventário proposto para os estudos, não um comprovante de compra. Preços ficam em branco para cotação datada. Confirme modelo, pinagem, tensão e protocolo do laboratório antes da montagem.
